# 硬件、预算与实机准备

这里合并早期架构/预算/验收文档中的有效信息。当前软件状态和命令以 [主 README](../README.md) 为准，
接口以 [interfaces.md](interfaces.md) 为准。以下设计目标不是已完成的实机验收结果。

## 已确认和待定项

- Orange Pi 5，8GB，Ubuntu 22.04，机载 C++ 推理与任务决策；地面电脑用于训练、编译、仿真和日志分析。
- MicoVIO 接 PX4，香橙派通过另一条 MAVLink 串口读取融合定位，不使用 GPS。
- 普通前向 USB 相机仍在选型；已有 D435i 保留为可用软件后端。天地飞遥控器/接收机已拥有。
- 固定真实裁判装甲板，首版使用 YOLOv8 红蓝检测；整板尺寸约 135×125 mm，不等于有效接触区域尺寸。
- 前期新增预算约 1500 元，不含已有 D435i 和遥控链路；能否借用机体/充电器仍需确认。
- PX4 飞控具体板型/revision/固件、接收机输出协议、电机/电调/桨、电池容量和串数、供电与散热尚待选定实测。

动力电池沿用早期锂聚合物原型路线，电容供电没有进入实现。选型应依据带全部载荷和保护罩的推力、
电流、压降与续航测量；项目没有给未知真机填写 KV、速度、倾角或推力参数。

## MicoVIO 资料与连接

原始宣传图保留在 [test_1](../test_1/DEE2E937B176163C7ABFBC54C6220E26.jpg)。图中写明 MAVLink 2、
921600 baud、8N1、3.3 V LVTTL 信号、5 V 供电、下视安装，典型更新率 40 Hz。
1% 漂移等宣传值不能作为接触精度保证。图中未定义消息 ID、针序、完整坐标/时间语义和安装外参，需厂家手册核对。
5 V 供电不代表信号线能承受 5 V；对地 ToF 高度不能当作前方装甲板距离。

MicoVIO 到 PX4 的安装方向与杆臂在飞控侧配置。香橙派读取融合结果前，先证明 PX4 估计器成功融合；
只在 QGC 中看到数值不能代替融合有效性验证。光流如另行使用，需要匹配的下视测距、纹理和安装条件。

电池分别向动力、飞控电源模块、计算板/相机稳压供电。计算板与相机负载不经飞控遥测口取电。
串口电平、共地、供电针序与接收机协议按实际硬件手册确认。接收机直接接飞控，不依赖香橙派转发接管。

Orange Pi 实机需记录 ARM64 系统镜像、内核、相机/SDK 版本、PX4 固件和模型哈希；
x86_64 可执行文件不能直接在 ARM64 运行。当前 OpenCV CPU 后端未使用 RKNN/NPU，板端吞吐量和热稳定性待测。
D435i 的 USB 3 协商、供电、室外反光及近距离失效范围需实测；源码支持 SDK 不等于相机已验收。

## 场地、机械与标定

约 100 m³ 不能直接转成导航边界。需要测量长、宽、净高、目标高度/朝向、机库、恢复点、返航路线和可落地区域。
相机、机体、接触头和机库分别有几何约束：`body_T_camera`、触头偏置、有效接触区、当前 `map_T_odom`
都要有实测依据；不能把相机中心或框中心当成接触头中心。

软触头的回程、触发力、行程、保护罩变形、视场遮挡、重心和振动需要检查。
接触时相机仍应有有效观测；对测距失效不能用旧深度或盲飞时间补齐。
预接触停止余量应覆盖速度×端到端延迟、制动距离、定位/测量误差及机构余量。

## 后续验收顺序

1. 台架：供电、相机取流、PX4 融合、串口时间同步、遥控接管和接触传感器。
2. 定位与观测：带全部载荷验证基础飞行；静止世界目标在无人机移动后仍保持合理世界坐标。
3. 仿真：坐标轴、时钟跳变、估计器 reset、目标丢失、感知/任务进程退出、模式接管、路径整段碰撞。
4. 预接触：自主接近并停在站位点，反复验证退出行为，再考虑受控接触。
5. 接触与回收：独立接触事件、有效区域证据、接触后健康、空闲退路、机库重定位和确认着陆。

首次月度规划为第 1 周台架/模型、第 2 周定位/标定/仿真、第 3 周预接触、第 4 周受控接触和日志复盘；
它不是进度承诺。旧设计的延迟 p95≤150 ms、更新≥10 Hz、持续 10 分钟和 8/10 次完整流程为待评估目标，
不是当前测试成绩。无数据/权重、硬件或定位验收未通过时不能声称已完成该阶段。

接触成功需要有效的目标区域证据、独立接触事件及正常退出。亮灯或丢目标均不能替代这三者。
返回起点附近和精确降入机库需分开验收；光流/VIO 漂移及接触后 reset 都可能使旧 home 失效。
下一阶段应保存观测、任务、接触事件、模型/配置哈希、视频与 PX4 ULog，并明确其时间对应关系。

## 比赛约束原始记录

原规则 PDF 保留在项目根目录：[2027 前瞻手册](<../RoboMaster 2027 高校系列赛规则变更前瞻手册（20260909）.pdf>)。

早期重量范围 150～249 g，尺寸关系 `y = -0.001225x + 0.3225`（y 为 kg，x 为 mm），
长宽高均不超过 x；150/200/249 g 对应 x 约 140.8/100/60 mm。
原型阶段曾允许放宽尺寸重量，该例外不能被表述为比赛合规。
